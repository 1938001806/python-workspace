## 第一部分：你已经掌握的「类」知识全景图

你现在已经能熟练运用以下四大核心技能：**定义类**、**初始化**、**定义方法**、**继承与重写**。

### 1. 完整示例：定义、初始化、方法、继承、重写、实例化

```python
# 1. 定义类（画图纸） & 2. 初始化（出厂设置）
class Animal:
    # 构造函数：造对象时自动执行
    def __init__(self, name, age):
        self.name = name  # 实例属性（每个动物独有的名字）
        self.age = age    # 实例属性（每个动物独有的年龄）

    # 3. 定义方法（类里面的函数，必须带 self）
    def speak(self):
        print(f"{self.name} 发出了声音！")

    def birthday(self):
        """每过一次生日，年龄 +1。演示 self 可以修改对象自己的数据。"""
        self.age += 1
        print(f"{self.name} 现在 {self.age} 岁了。")


# 4. 继承（子承父业）：Dog 自动拥有 Animal 的一切
class Dog(Animal):
    def __init__(self, name, age, breed):
        # 呼叫老爸初始化（super 的妙用）
        super().__init__(name, age)
        self.breed = breed  # 子类独有的属性：品种

    # 5. 方法重写（覆盖老爸的方法）
    def speak(self):
        print(f"{self.name} 是一只 {self.breed}，它汪汪叫！")


# 6. 实例化（造真狗） & 调用方法
my_dog = Dog("旺财", 3, "中华田园犬")
my_dog.speak()     # 输出：旺财 是一只 中华田园犬，它汪汪叫！
my_dog.birthday()  # 输出：旺财 现在 4 岁了。—— 这个方法没重写，用的是父类的
```

运行结果：

```text
旺财 是一只 中华田园犬，它汪汪叫！
旺财 现在 4 岁了。
```

**关键点拆解：**

| 语法 | 名称 | 作用 | 什么时候执行 |
| --- | --- | --- | --- |
| `class Animal:` | 类定义 | 声明一张图纸 | 程序加载到这一行时 |
| `def __init__(self, ...)` | 构造方法 | 出厂设置，给对象填初始数据 | `Dog("旺财", 3, ...)` 那一刻自动执行 |
| `self.name = name` | 实例属性 | 挂在「这个对象」身上的变量 | 同上 |
| `super().__init__(...)` | 父类调用 | 让父类帮它把公共部分装配好 | 子类 `__init__` 执行过程中 |
| `my_dog.speak()` | 方法调用 | 让这个对象做事 | 你写下这一行时 |

### 2. 五条核心认知

- `class` 是**图纸**。
- `__init__` 是**出厂设置**。
- `self` 代表当前的「那个具体的对象」。
- `super()` 让子类**白嫖**父类的功能。
- **重写**就是「儿子觉得老爸的方法不好用，自己写个同名的」。

> ⚠️ 关于 `self` 的最大误解：`self` 不是你写的参数，是 Python **自动帮你传**进去的。
> `my_dog.speak()` 看起来没传参，实际等价于 `Dog.speak(my_dog)`，`my_dog` 就变成了方法里的 `self`。
> 所以「忘记写 `self`」是新手报错排行榜第一名。

### 3. 属性查找：对象到底去哪里找变量

当你写 `obj.xxx` 时，Python 的查找顺序是：

1. 先看**对象自己**有没有 `xxx`（实例属性，即 `self.xxx = ...` 存进去的）；
2. 自己没有，就去**它所属的类**里找（类属性）；
3. 类里也没有，就沿**继承链**一层层往上找（父类 → 爷爷类 → …）；
4. 全程没找到 → 抛出 `AttributeError`。

```python
class Dog:
    species = "犬科动物"      # 类属性：图纸上写的公共说明

    def __init__(self, name):
        self.name = name      # 实例属性：每只狗独有


dog1 = Dog("旺财")
print(dog1.species)  # 犬科动物 —— 自己那没有，去类里找到了
print(Dog.species)   # 犬科动物 —— 直接通过类名也能读
```

这条规则解释了下面「神功 2」里所有让人困惑的现象。

## 第二部分：你「还没学到」的进阶神功（非常实用）

这部分属于书本第 9 章的后半部分，或者更进阶的教程内容。你现在提前学了，以后看别人的代码就不会懵了。

### 神功 1：`__str__` 魔法方法（让打印对象变好看）

如果你现在写 `print(my_dog)`，电脑会打印出一串极其难看的 `<__main__.Dog object at 0x000001>`。

加上 `__str__` 之后，你一 `print` 这个对象，它就会自动调用这个方法，给你返回一句人话。

```python
class Cat:
    def __init__(self, name):
        self.name = name

    # 魔法方法：只要 print(对象)，就会自动执行这里
    def __str__(self):
        return f"这是一只名叫 {self.name} 的猫。"


my_cat = Cat("优米")
print(my_cat)          # 输出：这是一只名叫 优米 的猫。
print(str(my_cat))     # 同上，print 内部就是先调用 str()
```

**两个必须记住的区别：**

| 方法 | 触发场景 | 语义 | 返回值要求 |
| --- | --- | --- | --- |
| `__str__` | `print(obj)`、`str(obj)`、f-string 插值 | 给人看的，可读 | 必须是 `str`，否则报 `TypeError` |
| `__repr__` | 交互式环境直接敲变量名、`repr(obj)`、放进列表里打印 | 给程序员看的，尽量像「能重建对象的代码」 | 必须是 `str` |

```python
class Cat:
    def __init__(self, name):
        self.name = name

    def __repr__(self):
        return f"Cat(name={self.name!r})"


cats = [Cat("优米"), Cat("咪咪")]
print(cats)   # [Cat(name='优米'), Cat(name='咪咪')]  ← 列表里用的是 __repr__
```

> 💡 实战建议：**先写 `__repr__`**。因为当你没写 `__str__` 时，Python 会退回去用 `__repr__`；反过来则不行。写一个 `__repr__` 就能让 `print` 和调试都变好看。
> 另外，标准库 `dataclasses` 能帮你自动生成 `__init__` / `__repr__` / `__eq__`：

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

print(Point(1, 2))  # Point(x=1, y=2) —— 一行代码都没多写
```

### 神功 2：类属性（大家共享的公共财产）

之前你写的 `self.name` 是**实例属性**（每只狗都不一样）。
如果你想定义一个属性，让所有造出来的对象**共享**，就放在类里面，但**不要加 `self`**。

```python
class Dog:
    # 类属性：放在类里面，但没有 self。所有狗共享这一个属性。
    species = "犬科动物"

    def __init__(self, name):
        self.name = name  # 实例属性：每只狗自己独有


dog1 = Dog("旺财")
dog2 = Dog("大黄")

print(dog1.species)  # 犬科动物
print(dog2.species)  # 犬科动物

# 改一下类属性，所有的狗都会跟着变
Dog.species = "食肉目犬科"
print(dog1.species)  # 食肉目犬科
print(dog2.species)  # 食肉目犬科
```

**类属性的两大经典用途：**

```python
class Dog:
    count = 0  # 用途一：做计数器，统计造了多少只狗

    def __init__(self, name):
        self.name = name
        Dog.count += 1  # 注意：用类名改，不要用 self 改（见下方陷阱）


a, b, c = Dog("旺财"), Dog("大黄"), Dog("豆豆")
print(Dog.count)  # 3


class Config:
    # 用途二：存放常量/默认值，全类共享，省内存
    max_retry = 3
    version = "1.0.0"
```

**⚠️ 必须避开的陷阱：`obj.attr = value` 会「遮蔽」类属性，而不是修改它。**

```python
# 接上文：dog1、dog2、Dog 来自「神功 2」第一个代码块
dog1.species = "吉娃娃"   # 这行给 dog1 造了一个自己的实例属性！
print(dog1.species)       # 吉娃娃     ← dog1 自己的
print(dog2.species)       # 食肉目犬科 ← 别的狗没受影响
print(Dog.species)        # 食肉目犬科 ← 类属性本身也没变
print(dog1.__dict__)      # {'name': '旺财', 'species': '吉娃娃'} —— 字典里已经有了
del dog1.species          # 删掉实例属性后，又找回类属性了
print(dog1.species)       # 食肉目犬科
```

同理，`Dog.count += 1` 若写成 `self.count += 1`，第一行读取时走类属性、赋值时却在对象身上新建属性——结果是「每只狗各自数自己的」，总数永远是 1。**要改类属性，就用类名改。**

可变类属性（列表、字典）更危险，`append` 会真的影响所有对象：

```python
class Dog:
    toys = []  # 所有狗共享同一个列表对象！

d1, d2 = Dog(), Dog()
d1.toys.append("飞盘")
print(d2.toys)  # ['飞盘']  ← d2 莫名其妙多了个玩具
```

### 神功 3：私有属性（给你的数据上把锁）

在 Python 里，如果你在属性名前面加两个下划线 `__`（比如 `__password`），这就变成了**私有属性**。外部的人不能直接修改它，这是一种保护机制。

```python
class BankAccount:
    def __init__(self):
        # 加了双下划线，这就是私有属性，外部不能直接 . 出来
        self.__money = 1000

    def show_money(self):
        print(f"你的余额是：{self.__money}")

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存钱必须是正数！")   # 这就是「上锁」的意义：入口校验
        self.__money += amount

    def withdraw(self, amount):
        if amount > self.__money:
            print("余额不足，取款失败")
            return
        self.__money -= amount


account = BankAccount()
account.show_money()  # 可以正常运行：你的余额是：1000

# print(account.__money)  ← 强行访问会直接报错！
# AttributeError: 'BankAccount' object has no attribute '__money'
# 电脑会大喊：「这是私房钱，你不能直接看！」

try:
    account.deposit(-50)     # 金额非法，被方法内部的校验拦下
except ValueError as e:
    print("拦截成功：", e)    # 输出：拦截成功： 存钱必须是正数！

account.withdraw(2000)       # 余额不足：不会报错，但也不会扣成负数
account.show_money()         # 你的余额是：1000
```

**真相：这不是真私有，而是「名称改写」（name mangling）。**
Python 把 `__money` 改名成 `_类名__属性名`，目的是防止子类不小心覆盖父类的属性。

```python
# 接上文：account 来自上一个 BankAccount 示例
print(account._BankAccount__money)  # 1000 —— 硬要访问也拿得到
```

> 结论：Python 的哲学是「**我们都是成年人**」。私有只是拦君子、不拦小人，真正的安全要靠**在方法里做校验**。

**单下划线 `_name` 的约定：** 表示「这是内部用的，别从外面调」，但**语法上完全能访问**。你在别人代码里大量见到它，含义就是「内部实现，随时可能变」。

**`@property`：把方法伪装成属性，这是 Pythonic 的做法。**

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius  # 看起来是直接赋值，其实自动走了下面的 setter

    @property                      # getter：读 circle.radius 不用加括号
    def radius(self):
        return self._radius

    @radius.setter                 # setter：写 circle.radius = x 时自动校验
    def radius(self, value):
        if value <= 0:
            raise ValueError("半径必须大于 0")
        self._radius = value        # 真正存下来的名字要带单下划线，否则无限递归！

    @property                      # 只读属性：只定义 getter，不给 setter
    def area(self):
        return 3.14159 * self._radius ** 2

    @radius.deleter                # deleter：del circle.radius 时触发
    def radius(self):
        print("半径被删掉了")


c = Circle(2)
print(c.radius)    # 2 —— 像属性一样读，其实执行了 getter
print(c.area)      # 12.56636 —— 不用加括号
c.radius = 5       # 触发 setter，校验通过
# c.radius = -1    # ValueError: 半径必须大于 0
# c.area = 100     # AttributeError: property 'area' of 'Circle' object has no setter
del c.radius       # 半径被删掉了
```

> ⚠️ **两个必踩的坑：**
> 1. **getter 和 setter 必须同名**，且 `@radius.setter` 必须写在 `@property def radius` **之后**，否则报 `NameError: name 'radius' is not defined`。
> 2. setter 里存的变量名（`self._radius`）**不能和 property 名相同**。写成 `self.radius = value` 会再次触发 setter，导致**无限递归**直至 `RecursionError`。

好处：外部调用方写的代码依然是 `obj.xxx`，但你在内部获得了**校验、计算、日志**的能力，而且不需要把已有代码全部改成 `obj.get_xxx()`。

**进阶：`__slots__`**（大型项目里省内存、并且能拦截拼错的属性名）

```python
class Point:
    __slots__ = ("x", "y")   # 只允许这两个属性

    def __init__(self, x, y):
        self.x, self.y = x, y

p = Point(1, 2)
# p.z = 3   ← AttributeError: 'Point' object has no attribute 'z'（帮你抓拼写错误）
```

### 神功 4：类的三种方法（普通方法、类方法、静态方法）

除了你常用的 `def speak(self)`（普通方法），还有两种极少用到、但在做大型项目时会出现的工具：

```python
class Calculator:
    name = "计算器"

    # 1. 普通方法（你已掌握）：必须传 self，用来处理对象自己的数据
    def add(self, a, b):
        print(f"我是 {self.name}")
        return a + b

    # 2. 静态方法：加 @staticmethod，不传 self。就是一个纯粹挂在这的工具
    @staticmethod
    def sub(a, b):
        return a - b

    # 3. 类方法：加 @classmethod，传 cls。用来操作类属性
    @classmethod
    def info(cls):
        print(f"我是{cls.name}图纸")


print(Calculator.sub(5, 3))  # 输出：2 —— 静态方法直接类名调用，不用造对象
Calculator.info()            # 我是计算器图纸
Calculator().add(1, 2)       # 普通方法必须先造对象
```

**三者对照表：**

| 类型 | 装饰器 | 第一个参数 | 能访问实例属性吗 | 典型调用方式 | 什么时候用 |
| --- | --- | --- | --- | --- | --- |
| 实例方法 | 无 | `self`（自动传） | ✅ 能 | `obj.method()` | 需要操作对象数据（99% 的情况） |
| 类方法 | `@classmethod` | `cls`（自动传类本身） | ❌ 不能 | `Class.method()` | 操作类属性；**做多种构造方式** |
| 静态方法 | `@staticmethod` | 无自动参数 | ❌ 不能 | `Class.method()` | 逻辑上属于这个类，但用不到任何属性 |

**类方法最实用的场景：多种「出厂设置」（备用构造器）**

```python
class Date:
    def __init__(self, year, month, day):
        self.y, self.m, self.d = year, month, day

    @classmethod
    def from_string(cls, s):
        """Date.from_string('2026-11-01') —— 用字符串造日期"""
        y, m, d = s.split("-")
        return cls(int(y), int(m), int(d))   # 用 cls 而不是类名，子类也能正确工作

    def __str__(self):
        return f"{self.y}-{self.m:02d}-{self.d:02d}"


print(Date.from_string("2026-11-01"))  # 2026-11-01
```

> 📌 新手提示：先不用管类方法和静态方法，只要知道它们叫这个名字，以后遇到查一下就行。**优先级：实例方法 >>> 其余两个。**

## 第三部分：超纲但会遇到的补充知识

### 多继承与 MRO（儿子有两个爹时，听谁的？）

```python
class A:
    def hi(self):
        print("我是 A")

class B:
    def hi(self):
        print("我是 B")

class C(A, B):   # 括号里可以写多个父类，越靠前优先级越高
    pass

C().hi()            # 我是 A
print(C.__mro__)    # (C, A, B, object) —— 这条查找路线就叫 MRO
help(C)             # 交互式环境里看继承树，非常好用
```

- 查找顺序由 **MRO**（Method Resolution Order，C3 线性化算法）决定，可用 `类名.__mro__` 或 `mro()` 查看。
- 所有类最终都继承自 `object`。
- 菱形继承（D 继承 B 和 C，B/C 都继承 A）时，`super()` 会保证 **A 只被执行一次**——这正是必须用 `super()` 而不是手写 `A.__init__(self)` 的原因。
- 实战建议：**尽量少用多继承**。真要用，推荐「一个主基类 + 若干 Mixin（只提供一组能力的 mixin 类）」的模式。

### 常用魔法方法速查表

魔法方法＝以 `__` 开头、以 `__` 结尾的方法，由 Python 在特定时机**自动调用**。见到 `__xxx__` 不必害怕，它只是个「回调钩子」。

| 方法 | 何时自动触发 | 例子 |
| --- | --- | --- |
| `__init__` | 实例化后 | `Dog("旺财", 3)` |
| `__str__` | `print` / `str()` | 人话描述 |
| `__repr__` | 调试显示 / 列表内 | 可编程描述 |
| `__len__` | `len(obj)` | 让对象支持 `len` |
| `__eq__` | `a == b` | 自定义「相等」的定义 |
| `__lt__` | `a < b` | 让对象可排序 |
| `__hash__` | 放进 `set` / 当 `dict` 键 | 配 `__eq__` 一起写 |
| `__getitem__` | `obj[k]` | 支持索引访问 |
| `__iter__` / `__next__` | `for x in obj` | 支持遍历 |
| `__contains__` | `k in obj` | 支持 `in` 判断 |
| `__call__` | `obj()` | 让对象像函数一样被调用 |
| `__enter__` / `__exit__` | `with obj:` | 支持上下文管理（自动关文件） |

```python
class Bookshelf:
    def __init__(self):
        self.books = []

    def add(self, book):
        self.books.append(book)

    def __len__(self):        # 让 len() 能用
        return len(self.books)

    def __getitem__(self, i): # 让 [] 能用
        return self.books[i]

    def __contains__(self, name):  # 让 in 能用
        return any(b == name for b in self.books)


shelf = Bookshelf()
shelf.add("Python 入门")
print(len(shelf))                  # 1
print(shelf[0])                    # Python 入门
print("Python 入门" in shelf)      # True
for b in shelf.books:              # 定义了 __iter__ 就能直接 for shelf
    print(b)
```

### `isinstance` 与 `type`：怎么确认一个对象是什么

```python
# 接第一部分：Animal / Dog / my_dog 来自最初的示例
my_dog = Dog("旺财", 3, "中华田园犬")

isinstance(my_dog, Dog)     # True
isinstance(my_dog, Animal)  # True  ← 继承链上层层都算！多态判断靠它
type(my_dog) is Dog         # True
type(my_dog) is Animal      # False ← type 只认亲爹，不看爷爷
```

> 判类型**一律优先用 `isinstance()`**，因为它尊重继承。

## 第四部分：常见坑与排错对照表

| 你写的代码 | 报错信息 | 真正原因 | 修法 |
| --- | --- | --- | --- |
| `def speak(): ...` 然后 `obj.speak()` | `speak() takes 0 positional arguments but 1 was given` | 忘了 `self`；Python 自动传了对象进去 | 改成 `def speak(self):` |
| `def __init(name):` | `TypeError: Dog() takes no arguments` | `__init__` 拼错（少了尾部 `__`） | 严格写成 `__init__` |
| `self.name = name` 写在方法里但 `__init__` 中没定义 | `AttributeError: 'Dog' object has no attribute 'name'` | 属性从未创建，用的时候还不存在 | 所有实例属性在 `__init__` 里先声明 |
| 在 `__init__` 里用 `self.name` 却拿不到外部值 | 值一直是默认值 | 实例化时没传参，或参数名对不上 | 检查 `Dog("旺财", 3)` 的参数个数与顺序 |
| `Dog.species = x` 之后部分对象没变 | 无报错，行为诡异 | 之前不小心用 `obj.species = y` 建了实例属性遮蔽 | 统一用类名改类属性 |
| `account.__money` | `AttributeError` | 名称改写 | 用公开方法，或理解后使用 `@property` |
| `super().__init__(name, age)` 写了却没生效 | `AttributeError: 'Dog' object has no attribute 'name'` | 子类自己重写了 `__init__`，但父类那行没被调用；或参数顺序传错 | 子类 `__init__` 第一行就写 `super().__init__(...)`，别放到方法末尾 |
| 父类有 `__x` 私有属性，子类访问不到 | `AttributeError` | 名称改写带类名，`_父类名__x` 与 `_子类名__x` 是两个东西 | 通过父类提供的公开方法访问 |
| 方法改不了对象数据（如列表被替换） | 外部看到旧值 | 用 `self.x = ...` 以外的方式传参，或传的是不可变对象 | 用 `return` 返回新值再赋值 |
| 循环改对象 `for d in dogs: d = ...` | 列表没变 | 重新绑定变量名不影响原对象 | 改成 `d.name = ...` 或 `dogs[i] = ...` |

**三个高频心法：**

1. **实例属性全部在 `__init__` 里登记完毕**，一眼能看清这个对象有哪些数据。
2. **报错第一眼看最后一行**：`AttributeError`＝名字不对；`TypeError`＝参数个数不对；`NameError`＝变量根本没定义。
3. **不确定就 `print(obj.__dict__)`**：它直接告诉你这个对象身上到底挂了哪些属性、值是多少。

> 要求：金额必须为正数；余额不足时取款不能失败成负数；写一段测试代码验证外部无法直接改 `__balance`。

> 父类 `Shape` 有空方法 `area()`；子类 `Rectangle(w, h)` 与 `Circle(r)` 各自重写。
> 要求：用 `@property` 让面积只读；把多个图形放进列表，循环调用 `area()` 体会**多态**。

### 参考答案

```python
# ---------- 练习 1 ----------
class Student:
    school = "阳光小学"          # 类属性：全校共享

    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.scores = []         # 注意：在 __init__ 里 [] 才是每人的独立列表

    def add_score(self, score):
        if not 0 <= score <= 100:
            raise ValueError(f"成绩非法：{score}")
        self.scores.append(score)

    def avg(self):
        if not self.scores:      # 空列表
            return 0
        return sum(self.scores) / len(self.scores)

    def __str__(self):
        return f"{self.name}，平均分 {self.avg():.1f}"


s = Student("小明", 10)
s.add_score(90)
s.add_score(85)
print(s)                 # 小明，平均分 87.5
print(Student.school)    # 阳光小学


# ---------- 练习 2 ----------
class Account:
    def __init__(self, balance=0):
        self.__balance = balance   # 私有：真正被改名成 _Account__balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金额必须为正数")
        self.__balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("取款金额必须为正数")
        if amount > self.__balance:
            raise ValueError(f"余额不足：当前 {self.__balance}，需要 {amount}")
        self.__balance -= amount

    def get_balance(self):         # 唯一的读取出口
        return self.__balance


acc = Account(100)
acc.deposit(50)
acc.withdraw(30)
print(acc.get_balance())     # 120
# print(acc.__balance)       # AttributeError —— 外部确实拿不到
# acc.__balance = 999999     # 这行不报错！但它只是新建了一个无关的公开属性，
                            # 因为 __balance 已被改写，真正的余额纹丝不动。
print(acc.get_balance())     # 120 —— 说明「锁」生效了


# ---------- 练习 3 ----------
import math


class Shape:
    def area(self):
        raise NotImplementedError("子类必须实现 area()")


class Rectangle(Shape):
    def __init__(self, w, h):
        self.w = w
        self.h = h

    @property
    def area(self):           # 用 property 重写父类方法 → 调用时不用加括号
        return self.w * self.h


class Circle(Shape):
    def __init__(self, r):
        self.r = r

    @property
    def area(self):
        return math.pi * self.r ** 2


shapes = [Rectangle(3, 4), Circle(2), Rectangle(2, 2)]
for s in shapes:
    print(f"{type(s).__name__}: {s.area:.2f}")   # 多态：同一句代码，各算各的
# Rectangle: 12.00
# Circle: 12.57
# Rectangle: 4.00
```

> `raise NotImplementedError` 的用途：把父类方法声明成「**必须被子类重写**」的模板。以后你会见到更正式的写法——`abc.ABC` + `@abstractmethod`。

## 附：终极复习口诀

- **图纸**（`class`）里装的是**属性**（变量）和**方法**（`def`）。
- **`self` 是身份的证明**，代表当前这个具体的对象。
- **`super()` 是认祖归宗**，用来借用老爸的功能。
- **`__init__` 是出生时的啼哭**（自动初始化），**`__str__` 是自我介绍**。
- **类属性写图纸上，实例属性挂身上**；改图纸要写类名，写 `self` 只是给自己化妆。
- **双下划线是保险箱，`@property` 是带门禁的窗口。**
- **看到 `__xxx__` 别慌，那是 Python 在按门铃，不是你该调的方法。**
