## 学习顺序建议（不是文件编号顺序）

```
① 基础语法 → ③ 小游戏 → ⑧ 计算器 → ② 通讯录演进 → ⑦ 异常处理 → ⑨ 单元测试 → ④ 数据分析 → ⑤ 爬虫 → ⑥ 面向对象 → 类与面向对象 → ⑩ pygame
```

理由：③ 的两个游戏是你目前**输入校验写得最完整**的代码，紧接 ① 最顺；⑧ 用同一套 `input` 校验但多了浮点与格式化，紧跟 ③；⑦ 放在 ② 之后，是因为要用你自己的 `load_data` 当正面教材；**⑨ 紧跟 ⑦**——异常处理讲完就该知道「怎么证明它真的挡住了」；⑥ 放最后，是因为面向对象要用「已经能写出可用程序」当前提；⑩ 需要 ⑥（四个文件全是类）+ ⑦（帧率与几何耦合）+ ⑨（搬进函数才能测）作为前提。
