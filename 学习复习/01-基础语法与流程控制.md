### 1. average-01.py —— 提示语从「第 0 个」开始

原代码 [average-01.py:7-9](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/average-01.py#L7)：

```python
for i in range(5):
    s = int(input(f"请输入第{i}个成绩："))
    scores.append(s)
```

实际输出（喂入 85 92 78 60 99）：

```text
请输入第0个成绩：请输入第1个成绩：请输入第2个成绩：请输入第3个成绩：请输入第4个成绩：所有成绩：[85, 92, 78, 60, 99]
总分是414，平均分是82.8
```

**三处可改进：**

| 问题 | 位置 | 说明 |
| --- | --- | --- |
| 人类没有「第 0 个」 | `:8` | 循环变量从 0 起，展示要 `i + 1` |
| `int(input())` 裸奔 | `:8` | 输入 `abc` 直接 `ValueError` 崩掉 |
| 手写累加循环 | `:11-13` | Python 有内置 `sum()`，两行变一行 |

修正版（实测）：

```python
scores = []
while len(scores) < 3:                      # 想收几个就改这里，别用魔法数 5
    text = input(f"请输入第{len(scores) + 1}个成绩：").strip()
    try:
        s = int(text)
    except ValueError:
        print("必须是整数，重来")
        continue
    if not 0 <= s <= 100:                   # 链式比较，比 0 <= s and s <= 100 更清爽
        print("成绩要在 0~100 之间")
        continue
    scores.append(s)

print(f"所有成绩：{scores}")
print(f"总分是{sum(scores)}，平均分是{sum(scores) / len(scores)}")
```

实际输出（喂入 90 / abc / 200 / 85 / 77）：

```text
请输入第1个成绩：请输入第2个成绩：必须是整数，重来
请输入第2个成绩：成绩要在 0~100 之间
请输入第2个成绩：请输入第3个成绩：所有成绩：[90, 85, 77]
总分是252，平均分是84.0
```

注意看第 2、3 行：**`continue` 之后 `len(scores)` 没变，提示语仍是「第 2 个」**——这就是为什么用 `len(scores) + 1` 比用循环变量 `i` 更可靠：`i` 会把失败的输入也算进去。

> ⚠️ 另外 `scores` 是浮点除法的结果：`sum/len` 在 Python 3 里永远返回 `float`。想保留一位小数写 `{平均值:.1f}`。

**「请输入第个同学姓名」这句不通顺的话就是你的 bug**：字符串少了 `f` 和 `{i + 1}`。这类错误最阴险——**程序不报错，只是不对**。

```python
for i in range(3):

```

实测输出：

```text
请输入第1位同学姓名：请输入第2位同学姓名：请输入第3位同学姓名：全班一共录入了2位同学。
```

**列表速查（基于 `list-01.py` 前半段实测：`scores = [85, 92, 78, 60, 99]` → `append(100)` → `len` 打印 6）：**

| 想做 | 写法 | 记住 |
| --- | --- | --- |
| 取下标 | `scores[1]` → `92` | 从 0 开始 |
| 取倒数 | `scores[-1]` | 负下标从末尾数 |
| 切片 | `scores[1:3]` | **左含右不含**，得 `[92, 78]` |
| 加元素 | `scores.append(100)` | 改的是原列表，返回 `None` |
| 长度 | `len(scores)` → `6` | `append` 之后才 6 |
| 求和 | `sum(scores)` | 别手写累加 |
| 判空 | `if not classnames:` | 空列表本身就是 `False` |
| 遍历下标 | `for i, x in enumerate(lst, start=1):` | 需要编号时用 `enumerate` |

> 🚨 高频错误：`scores = scores.append(100)` 会把 `scores` 变成 `None`。`append` 原地修改，**没有返回值**，单独一行调用即可。

### 3. loop-01.py —— 负数被当成「不是数字」

原代码 [loop-01.py:16-22](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/loop-01.py#L16)：

```python
    if not text.isdigit():
        print("请输入数字")
        continue
    score = int(text)
    if score < 0 or score > 100:
        print("成绩必须在 0~100 之间")
        continue
```

实际输出（喂入 abc / 120 / **-5** / 85 / q）：

```text
请输入成绩（输入 q 退出）：请输入数字
请输入成绩（输入 q 退出）：成绩必须在 0~100 之间
请输入成绩（输入 q 退出）：请输入数字          ← 这里是 -5，本该说「必须在 0~100 之间」
请输入成绩（输入 q 退出）：85分，合格
```

**根因**：`str.isdigit()` 只认纯数字字符，负号 `-` 不是数字，所以 `"-5".isdigit()` 是 `False`。你的第 20 行范围检查**根本没机会执行**。同类陷阱还有 `"-5".isdecimal()`（同样 False）、`"3.14".isdigit()`（False）。

修正：先转 `int`，再判范围——把「能不能转成数字」和「数字合不合法」分成两层。

```python
    try:
        score = int(text)
    except ValueError:
        print("请输入数字")
        continue
    if score < 0 or score > 100:
        print("成绩必须在 0~100 之间")
        continue
```

实测（同样喂入 abc / 120 / -5 / 85 / q）：

```text
请输入数字
成绩必须在 0~100 之间        ← -5 现在走到正确的分支了
成绩必须在 0~100 之间        ← 120
85分，合格
```

> 📌 这条也提前预告了 `try/except` 的价值：**`isdigit()` 是「猜测」，`try: int()` 是「真做一遍」**。后者永远和 `int()` 的实际规则一致，不会有边角差异。等 07 号文档学异常处理时回头看这里会更清楚。

你注释掉的 [loop-01.py:3](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/loop-01.py#L3) 那句自我批评完全正确，值得单独记：

```python
if score < 100 or score < 0:    # ❌ 恒为真：任何数都满足其中之一
if score < 0 or score > 100:    # ✅ 拦截非法
if 0 <= score <= 100:           # ✅ 放行合法，推荐这种
```

**`or`/`and` 自检法**：写完把两个极端值代进去。`score < 100 or score < 0`，代入 `50`：`True or False` → `True`（本该放行却拦截了）→ 立刻发现写反。

### 4. count-01.py —— 同一个功能写了两遍，第二遍还锁不住

[Count-01.py:1-15](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/count-01.py#L1) 是有限次数版本，`:17-24` 是无限重试版本。实际输出（喂入 a b c d 谷明真 谷明真）：

```text
请输入你的名字（提示：姓谷）：不认识你！你还有 4 次机会。
...
请输入你的名字（提示：姓谷）：不认识你！你还有 1 次机会。

请输入你的名字（提示：姓谷）：欢迎回家！游戏结束。
请输入你的名字（提示：姓谷）：欢迎回家！游戏结束      ← 第二个循环也在跑
```

三个问题：

1. **两个循环是重复代码**。第二个 `while True` 永远不给退出上限，输错 100 次也照问——练手可以，正式版只能留一个。
2. **第一个循环少了 `.strip()`**（`:4` 直接用了原始输入），而第二个循环有（`:18`）。所以第一个循环输入 `" 谷明真 "` 会被判不认识。同一份逻辑的两个副本已经**行为不一致**了——这就是复制粘贴的代价，也正是 `def` 要解决的问题（见 [02-通讯录项目演进.md](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/%E5%AD%A6%E4%B9%A0%E5%A4%8D%E4%B9%A0/02-%E9%80%9A%E8%AE%AF%E5%BD%95%E9%A1%B9%E7%9B%AE%E6%BC%94%E8%BF%9B.md)）。
3. `:14` 的 `if count == 5` 依赖「循环自然结束」这个隐含事实。更稳的写法是 Python 自带的 `while...else`：

```python
for chance in range(5, 0, -1):                 # 5 4 3 2 1，一个循环搞定，不再需要 count
    name = input(f"请输入你的名字（提示：姓谷），还有 {chance} 次机会：").strip()
    if name == "谷明真":
        print("欢迎回家！")
        break
else:
    print("尝试次数太多，账号已锁定！")        # 只有「没被 break」才会执行
```

> 💡 `for/while...else`：**`else` 在循环正常跑完（没遇到 `break`）时执行**。用它来表达「次数用尽」比 `if count == 5` 更直白，也不会因为 `break` 后又改计数而失效。

```python
data = [1, 2, 3]
print(2 in data)          # True —— 只判断存在
[idx for idx, v in enumerate(data) if v == 2]   # [1] —— 还想要下标
```

### 6. check_age.py —— 本类写得最好的一个

[check_age.py:1-7](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/check_age.py#L1)：

```python
def check_age(age):
    return "已成年" if age >= 18 else "未成年"

assert check_age(18) == "已成年"
assert check_age(17) == "未成年"
print("全部通过")
```

实际输出：

```text
全部通过
```

做对的四件事：**函数有参数、有 `return`、边界值 18 单独测了、用 `assert` 自我校验**。这是本类里唯一带「测试」意识的文件。

两个知识点：

- **三元表达式** `A if 条件 else B` 只能用于「简短赋值」，别嵌套。判断复杂就老老实实写 `if/else`。
- **`assert` 会被 `-O` 优化掉**：`python -O check_age.py` 时所有 `assert` 直接不执行。所以 `assert` 只能用于**自查和练手**，绝不能当业务校验（那是 `if ... raise ValueError` 的活，见 [07-异常处理与程序健壮性.md](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/%E5%AD%A6%E4%B9%A0%E5%A4%8D%E4%B9%A0/07-%E5%BC%82%E5%B8%B8%E5%A4%84%E7%90%86%E4%B8%8E%E7%A8%8B%E5%BA%8F%E5%81%A5%E5%A3%AE%E6%80%A7.md)）。

## 二、本类知识点提炼

### 输入校验的标准三层（背下来）

```python
while True:
    text = input("请输入成绩：").strip()   # 第 0 层：去首尾空格
    if text.lower() == "q":
        break                              # 第 1 层：退出指令（必须在转数字之前）
    try:
        score = int(text)                  # 第 2 层：能不能变成数字
    except ValueError:
        print("请输入数字")
        continue
    if not 0 <= score <= 100:              # 第 3 层：数字合不合法
        print("成绩必须在 0~100 之间")
        continue
    print(f"收到合法成绩：{score}")
    break
```

**顺序不能乱**：先判退出 → 再转类型 → 最后判范围。`loop-01.py` 的负数 bug 就是把第 2 层写成了 `isdigit()`，导致第 3 层收不到负数。

### `break` / `continue` / `else` 三者对照

| 关键字 | 效果 | 典型用途 |
| --- | --- | --- |
| `break` | 立刻离开**整个**循环 | 猜对了、选退出 |
| `continue` | 跳过本次，回到循环开头 | 输入非法，重来 |
| `else`（接循环） | 循环**没被 `break`** 时执行 | 次数用尽的收尾 |

`break`/`continue` 只作用于**最内层**循环。双层循环里 `break` 只出内层，想同时出外层要有标志位，或把内层包进函数用 `return`。

### f-string 的三个必会写法

```python
name, avg = "张三", 82.833333
print(f"{name} 平均分 {avg:.1f}")          # 82.8        保留一位小数
print(f"{1234567:,}")                       # 1,234,567    千分位
print(f"{'abc':>10}|")                      #       abc|    右对齐占 10 格
print(f"{name!r}")                           # '张三'      调试看原样
```

## 三、易错清单（本类脚本里真实出现的）

| # | 症状 | 你的现场 | 根因 |
| --- | --- | --- | --- |
| 1 | 不报错但话不通 | `list-01.py:11`「请输入第个同学姓名」 | 字符串忘了加 `f` 和 `{}` |
| 2 | 负数走错分支 | `loop-01.py:16` | `isdigit()` 不认负号 |
