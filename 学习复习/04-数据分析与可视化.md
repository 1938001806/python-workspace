## 一、10_make_data.py —— `newline=""` 不是可选参数

[10_make_data.py:14-16](../10_make_data.py#L14-L16)：

```python
with open("scores.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data)
```

实际输出：`✅ 假数据 scores.csv 生成成功！`

Windows 文本模式会把 `\n` 翻译成 `\r\n`，而 `csv.writer` 自己也会写行结束符，两者叠加会出现 `\r\r\n`，Excel 打开多空行。`newline=""` 把换行控制权交给 `csv` 模块，是官方要求的写法。

生成的数据：

```text

```

### 动作对照

| 动作 | 代码 | 要点 |
| --- | --- | --- |
| 读 | `pd.read_csv("scores.csv")` [:3](../11_analysis.py#L3) | 首行自动变列名，不额外造索引 |
| 单条件筛 | `df[df["语文"] >= 60]` [:10](../11_analysis.py#L10) | 内层得到一列 True/False，外层按它挑行 |
| 多条件筛 | `df[(df["数学"] > 80) & (df["英语"] > 80)]` [:19](../11_analysis.py#L19) | 必须 `&`，每个条件都要括号 |
| 聚合 | `df["数学"].mean()` [:14](../11_analysis.py#L14) | `.sum() .max() .count() .std()` 同一套 |
| 选单列 | `df[df["英语"] < 60]["姓名"]` [:23](../11_analysis.py#L23) | 返回 `Series`，所以输出有 `Name: 姓名` |
| 派生列 | `df[[...]].sum(axis=1)` [:5](../12-total-points.py#L5) | 多列用双层方括号 |
| 排序 | `sort_values(..., ascending=False)` [:7](../12-total-points.py#L7) | 不改原表，必须重新赋值 |
| 取头 | `head(3)` [:11](../12-total-points.py#L11) | 索引跟着数据走，所以是 4、2、0 |

### 三个「为什么」

**① `axis=1` 是每人总分，`axis=0` 是每科合计。** 实测：

```text
axis=1: [255, 254, 259, 195, 275, 150]     # 6 个人
axis=0: [449, 474, 465]                     # 3 科
```

`axis` 指「沿哪个方向收缩」：`axis=1` 沿列方向收缩，每行得到一个值。

**② 多条件为什么不能用 `and`？** `and` 要求两边是单个布尔值，而 `df["数学"] > 80` 是一整列布尔值，会抛：

```text
ValueError: The truth value of a Series is ambiguous
```

pandas 用 `& | ~`，并且因为 `&` 优先级高于 `>`，每个条件都要加括号。

**③ 排序后索引为什么是 4、2、0？** `sort_values` 只重排行，索引跟着数据走。实测：

```text
排序后索引: [4, 2, 0, 1, 3, 5]
reset 后:   [0, 1, 2, 3, 4, 5]
```

想连续就加 `.reset_index(drop=True)`。`drop=True` 表示丢弃旧索引，不把它变成一列。

### 唯一需要改的命名

[11_analysis.py:23](../11_analysis.py#L23) 的 `bad_English_names` 混用了小写和大驼峰。PEP 8 对变量/函数要求全小写 + 下划线：`bad_english_names`。

| 对象 | 规范 | 例子 |
| --- | --- | --- |
| 变量、函数 | `snake_case` | `average_math`、`load_data` |
| 类 | `PascalCase` | `SmartCat`、`RandomWalk` |
| 常量 | `UPPER_SNAKE` | `MAX_ROUNDS`、`MAX_TIMES` |
| 列名 | 原样引用，错一个就 `KeyError` | `df["英语"]` |

## 三、12_charts.py —— 四处缺陷与真实后果

文件能跑（exit=0），但有两处**只有盯图才发现**。

### 缺陷 1：`plt.xlabel` 写两次，y 轴标题永远是空的

[12_charts.py:20-22](../12_charts.py#L20-L22)：

```python
plt.title("各科平均分对比图", fontsize=16)
plt.xlabel("科目", fontsize=12)
plt.xlabel("平均分", fontsize=12)     # 应为 ylabel
```

实测最终标签：

```text
柱图 xlabel -> 平均分 | ylabel -> ''
线图 xlabel -> 分数   | ylabel -> ''
```

「科目」被「平均分」覆盖，y 轴标题为空。折线图 [:34-35](../12_charts.py#L34-L35) 是同一个错误。

### 缺陷 2：`f"{v:1f}"` 少一个点，精度控制失效

[12_charts.py:25](../12_charts.py#L25)：

```text
f"{v:1f}"  -> 82.833333
f"{v:.1f}" -> 82.8
```

`:1f` 里的 `1` 是**最小总宽度**；`.1` 才是小数位数。少一个字符，六位小数全露出来，而且不报错。

### 缺陷 3：同样的 5 行写了两遍

[12_charts.py:11-15](../12_charts.py#L11-L15) 中 `subjects` 和 `average_scores` 各出现两次，一字不差。加第四科时要改两处。

### 缺陷 4：`plt.` 全局状态风格

`plt.figure()` 之后所有 `plt.xxx()` 都作用于「当前图」。本例每张图都先 `plt.figure()`，侥幸没串图；但只要中间插一次别的绘图调用就会画错对象。推荐 `fig, ax = plt.subplots()`，之后一律 `ax.xxx()`。

### 修正版（已实测出图）

```python
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

df = pd.read_csv("scores.csv")
subjects = ["语文", "数学", "英语"]
average_scores = [df[s].mean() for s in subjects]

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(subjects, average_scores, color=["skyblue", "orange", "lightgreen"])
ax.set_title("各科平均分对比图", fontsize=16)
ax.set_xlabel("科目", fontsize=12)
ax.set_ylabel("平均分", fontsize=12)
for i, v in enumerate(average_scores):
    ax.text(i, v + 1, f"{v:.1f}", ha="center", fontsize=12)
fig.savefig("bar.png", dpi=80)

fig2, ax2 = plt.subplots(figsize=(8, 5))
ax2.plot(df["姓名"], df["数学"], marker="o", color="red", linestyle="--")
ax2.set_title("学生数学成绩折线图", fontsize=16)
ax2.set_xlabel("姓名")
ax2.set_ylabel("分数")
ax2.grid(True)
fig2.savefig("line.png", dpi=80)
plt.show()
```

验证输出：

```text
annotations: ['74.8', '79.0', '77.5']
柱图轴标签: 科目 平均分
线图轴标签: 姓名 分数
bar.png 13307 bytes | line.png 21511 bytes
```

四个问题一次解决，并且用 `savefig` 落盘，调参时不用反复弹窗。

### 中文乱码那两行为什么必须成对

```python
plt.rcParams['font.sans-serif'] = ['SimHei']    # 管汉字
plt.rcParams['axes.unicode_minus'] = False       # 管负号
```

换中文字体后，负号 `-` 会按中文字符去找，找不到就显示方框。两行必须成对；你写对了，实测零字体告警。

## 四、pandas 陷阱：筛选结果是副本

实测：

```text
sub = df[df["数学"] > 80]
sub["备注"] = "优秀"
原 df 有 '备注' 列吗: False
```

筛选出来的表是副本，在副本上加列不会改原表。要改原表用 `.loc`：

```python
df.loc[df["数学"] > 80, "备注"] = "优秀"
```
