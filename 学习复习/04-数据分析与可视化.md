### 三个「为什么」，答不上来就说明还没懂

**① 为什么 `axis=1` 是每人总分，`axis=0` 是每科合计？** 实测：

```text
axis=1(每行/每人总分): [255, 254, 259, 195, 275, 150]     ← 6 个人各一个数
axis=0(每列/每科合计): [449, 474, 465]                     ← 3 科各一个数
```

记法：`axis` 指**沿着哪个方向收缩**。`axis=1` 沿横向（列）收缩，每个**行**得到一个值。

**② 为什么 `df[cond]["姓名"]` 不能写成 `df[cond and cond]`？** 实测过 `11_analysis.py:19` 的 `&`，但要知道 `and` 为什么会崩：`and` 要求两边是**单个布尔值**，而 `df["数学"] > 80` 是一整列布尔值，Python 不知道「这一列算真还是假」，于是抛 `ValueError: The truth value of a Series is ambiguous`。**pandas 里做逻辑运算只能用 `&`（与）`|`（或）`~`（非），且必须给每个条件加括号**——因为 `&` 的优先级比 `>` 高，不加括号会变成「先与后比较」。

**③ 为什么排序后索引是 4、2、0 而不是 0、1、2？** `sort_values` 只重排行，**索引跟着数据走**（索引是这行数据原来在文件里的位置）。想让它连续，加一句 `df = df.sort_values(...).reset_index(drop=True)`。

### 唯一需要改的一处：变量命名

[11_analysis.py:23](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/11_analysis.py#L23) 的 `bad_English_names` 混合了小写和大驼峰。Python 变量名规范（PEP 8）是**全小写 + 下划线**：`bad_english_names`。你自己在学习总结里也记过这条。

顺带说清规范边界（只在「名字」层面）：

| 用途 | 规范 | 例子 |
| --- | --- | --- |
| 变量、函数 | `snake_case` | `average_math`、`load_data` |
| 类 | `PascalCase` | `SmartCat`、`AddressBook` |
| 常量（全大写） | `UPPER_SNAKE` | `MAX_TIMES = 5`（你在 09/10 里已经这么写了 ✓） |
| 列名 | 由数据决定，但**要原样引用** | `df["英语"]` 里空格/大小写错一个就 `KeyError` |

## 三、12_charts.py —— 四处缺陷与它们的真实后果

文件本身能跑（exit=0，两张图窗口正常弹出）。但有 4 个问题，其中 2 个**只有盯着图看才发现**。

### 缺陷 1：`plt.xlabel` 写了两次，y 轴标题其实是空的

[12_charts.py:20-22](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/12_charts.py#L20)：

```python
plt.title("各科平均分对比图", fontsize=16)
plt.xlabel("科目", fontsize=12)
plt.xlabel("平均分", fontsize=12)     # 应为 ylabel
```

后果实测：

```text
x 轴标签最终是: '平均分'        ← 「科目」被覆盖了
y 轴标签是: ''                 ← 空的，图上根本没有 y 轴标题
```

**不报错，只是图不对。** 折线图那段 [`:34-35`](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/12_charts.py#L34) 是完全相同的错误（x 轴显示成了「分数」）。

### 缺陷 2：`f"{v:1f}"` 少打一个点，小数位控制完全失效

[12_charts.py:25](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/12_charts.py#L25) `plt.text(i, v + 1, f"{v:1f}", ...)`。后果实测：

```text
f'{v:1f}'  -> '82.833333'    ← 想保留 1 位，实际输出 6 位小数
f'{v:.1f}' -> '82.8'         ← 正确写法（有小数点）
f'{v:.2f}' -> '82.83'
```

`:1f` 里的 `1` 被当成**最小总宽度**（宽度本来就超过 1，等于没限制），`.1f` 里的 `.1` 才是精度。这种「少一个字符」的错误在 f-string 里**特别常见且特别安静**。

### 缺陷 3：重复的 5 行

[12_charts.py:11-12](file:///E:/python%E6%BA%90%E7%A0%81/python%E5%B7%A5%E4%BD%9C%E5%8C%BA/lreaning/12_charts.py#L11) 与 `:14-15` 一字不差：

```python
subjects = ["语文","数学","英语"]
average_scores = [df["语文"].mean(),df["数学"].mean(),df["英语"].mean()]

subjects = ["语文","数学","英语"]              # ← 重复
average_scores = [df["语文"].mean(),df["数学"].mean(),df["英语"].mean()]   # ← 重复
```

而且第二遍手写三列，加第四科时要改两处。用推导式：

```python
subjects = ["语文", "数学", "英语"]
average_scores = [df[s].mean() for s in subjects]      # 加科目只改上面那一行
```

### 缺陷 4：`plt.` 全局状态风格，两图连画时最容易出错

`plt.figure()` 之后所有 `plt.xxx()` 都作用在「当前那张图」上。你这里恰好每张图都先 `plt.figure()`，所以侥幸没出问题。但只要中间多一句别的绘图调用，就会画到错的图上。**推荐显式拿到对象**：`fig, ax = plt.subplots()`，然后一律用 `ax.xxx()`。

### 修正版（已实测，两张 PNG 正常生成）

```python
import pandas as pd
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]        # 中文显示
plt.rcParams["axes.unicode_minus"] = False          # 负号显示（否则变方框）

df = pd.read_csv("scores.csv")
subjects = ["语文", "数学", "英语"]
average_scores = [df[s].mean() for s in subjects]

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(subjects, average_scores, color=["skyblue", "orange", "lightgreen"])
ax.set_title("各科平均分对比图", fontsize=16)
ax.set_xlabel("科目", fontsize=12)
ax.set_ylabel("平均分", fontsize=12)                # ylabel！
for i, v in enumerate(average_scores):
    ax.text(i, v + 1, f"{v:.1f}", ha="center", fontsize=12)   # .1f！
fig.savefig("bar.png", dpi=80)                      # 存文件，不依赖窗口

fig2, ax2 = plt.subplots(figsize=(8, 5))
ax2.plot(df["姓名"], df["数学"], marker="o", color="red", linestyle="--")
ax2.set_title("学生数学成绩折线图", fontsize=16)
ax2.set_xlabel("姓名")
ax2.set_ylabel("分数")
ax2.grid(True)
fig2.savefig("line.png", dpi=80)
plt.show()
```

验证输出：

```text
annotations = ['74.8', '79.0', '77.5']
柱图轴标签 -> '科目' '平均分'
线图轴标签 -> '姓名' '分数'
bar.png 生成: True 13778 bytes
line.png 生成: True 22982 bytes
```

四个问题一次解决：轴标签各归其位、小数一位、无重复行、对象式写法。**并且用 `savefig` 把图落盘**，这样调参时不用每次都弹窗，也方便贴到笔记里。

### 中文乱码那两行为什么必须成对出现

```python
plt.rcParams['font.sans-serif'] = ['SimHei']      # 管汉字
plt.rcParams['axes.unicode_minus'] = False         # 管负号 -
```

换中文字体后，负号 `-` 会被当成一个中文字符去找，找不到就显示成方框 □。所以只要设了中文字体，第二行就要跟上。你这两行写对了，实测**零字体告警**。

## 四、一个 pandas 陷阱（本类代码没踩，但下一步一定会）

我想验证「筛选后直接赋值」的行为，实测结果：

```text
sub = df[df["数学"] > 80]
sub["备注"] = "优秀"
原 df 有 '备注' 列吗: False        ← 修改只落在副本上，原表没动
```

**筛选出来的表是一个「副本」，在它上面加列/改值，原表不受影响。** 想要真的改到原表，用 `.loc` 一次性定位：

```python
df.loc[df["数学"] > 80, "备注"] = "优秀"      # 直接落到原 df
```

这条规则值得现在就记住，因为你的下一步（爬虫数据清洗）第一个会碰到的就是它。
